# How to Run WhatsApp Student Messenger

Here are the simple commands to run the application, run tests, or launch the packaged macOS app.

---

## 1. Quick Run (One Command)

From the project root directory, simply run:

```bash
./run.sh
```

---

## 2. Standard Terminal Run

If you want to run it step-by-step in your terminal:

```bash
# 1. Navigate to the project directory
cd /Users/wasee/Desktop/Wasee/Whatsapp

# 2. Activate the virtual environment
source .venv/bin/activate

# 3. Launch the desktop application
python main.py
```

---

## 3. Connecting Your Real WhatsApp Account (QR Code Scan)

1. Launch the app (`./run.sh` or `python main.py`).
2. Go to **⚙️ Settings** in the left sidebar.
3. Under **Messaging Integration**, select **WhatsApp Web (Real WhatsApp)**.
4. Click **`🔗 Open WhatsApp Web & Scan QR`**.
5. A browser window will open to `web.whatsapp.com`:
   - Open WhatsApp on your phone.
   - Tap **Settings** (or the three dots) → **Linked Devices** → **Link a Device**.
   - Point your phone at the screen to scan the QR code.
6. Once scanned, your session is saved locally in `data/whatsapp_session/` — you will **not** need to scan it again.
7. Any campaign you launch from **🚀 Campaigns** will now be dispatched directly through your connected WhatsApp account!

---

## 4. Anti-Restriction Feature (3/4/5 Message Variations)

To prevent WhatsApp spam restrictions and account bans from sending identical messages:
1. In **🚀 Campaigns**, under **Message Variations (Anti-Restriction)**, you can configure 3, 4, 5, or more distinct SMS designs.
2. Click **`+ Add SMS`** to add additional message designs (e.g. SMS #1, SMS #2, SMS #3, SMS #4).
3. Use variables like `{{name}}`, `{{batch}}`, `{{phone}}`, or `{Option 1|Option 2}` spintax.
4. When the campaign runs, messages automatically rotate sequentially across your students:
   - Student 1 receives **SMS #1**
   - Student 2 receives **SMS #2**
   - Student 3 receives **SMS #3**
   - Student 4 receives **SMS #4**
   - Student 5 receives **SMS #1** (cycles back)
5. In **Review & Confirm Campaign**, you can see a live multi-student preview showing the exact SMS design assigned to each recipient.

---

## 5. Run the Automated Tests

To run the full test suite (29 tests covering validation, import, templates, multi-variant rotation, campaigns, and reports):

```bash
source .venv/bin/activate
pytest -v
```

---

## 6. Run the Packaged macOS Application (.app)

The standalone build generated by PyInstaller is located in `dist/`. You can open it directly from the terminal:

```bash
open dist/WhatsAppStudentMessenger.app
```

Or locate it in Finder and double-click:
`/Users/wasee/Desktop/Wasee/Whatsapp/dist/WhatsAppStudentMessenger.app`

---

## 5. Rebuild the Standalone Executable

If you modify code and want to refresh the standalone `.app` bundle:

```bash
source .venv/bin/activate
pyinstaller whatsapp_messenger.spec
```

## 6. Running the WhatsPulse Next.js SaaS Website

We built a full, production-ready SaaS web platform inside the `web/` directory using Next.js 16, React 19, TypeScript, and Tailwind CSS.

### Start the Next.js SaaS in Development Mode:
```bash
cd /Users/wasee/Desktop/Wasee/Whatsapp/web
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser to view:
- **Public Landing Page**: High-converting sales page with live interactive Anti-Ban Simulator, ROI Savings Calculator, Features, Pricing ($19, $49, $99), and FAQs.
- **SaaS Web App**: Click **"Launch App"** or navigate directly to **[http://localhost:3000/app](http://localhost:3000/app)**:
  - 📊 **Overview**: Real-time deliverability stats, device status card, quick campaign launcher.
  - 🚀 **Campaigns**: Multi-SMS Anti-Restriction Studio with dynamic tabs (SMS #1, #2, #3...), live multi-student rotation preview, and simulated real-time queue dispatcher.
  - 👥 **Contacts & Students**: Recipient CRM with search, batch filters, status tags (`Active WhatsApp`, `No WhatsApp`), Add/Import modals.
  - 🛡️ **Message Variants**: Template library with multi-variant management.
  - 📱 **WhatsApp Connect**: Cloud Web QR code scanner hub.
  - 📈 **Reports & Audit**: Delivery reports and CSV exports.
  - ⚙️ **Settings & Billing**: Pro plan subscription manager, throttle jitter sliders, and developer API keys.

### Build and Start for Production:

```bash
cd /Users/wasee/Desktop/Wasee/Whatsapp/web
npm run build
npm run start
```
